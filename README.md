# 🚀 AI Code Tutor Studio

> Learn Programming with AI — Step by Step.

AI Code Tutor Studio is an AI-powered web application that teaches users how code works instead of simply generating answers.

It analyzes uploaded code, explains it line by line, visualizes execution, detects algorithms, and provides an interactive AI tutor for learning programming concepts.

---

# ✨ Features

## 🤖 AI Code Analysis

- Analyze complete source code
- Detect functions
- Detect classes
- Detect variables
- Detect loops
- Detect recursion
- Detect conditions
- Explain program purpose

---

## 📖 Step-by-Step Tutor

The AI explains code one logical step at a time.

Features:

- Previous / Next navigation
- Highlight current code line
- Beginner-friendly explanations
- Examples
- Context-aware learning

---

## 💬 AI Chat

Ask questions like:

- Why is this line needed?
- Explain simply.
- What happens if I remove this?
- Give me an example.
- Explain recursion.

The AI remembers the current code and learning progress.

---

## ▶ Dry Run Visualizer

Visual execution including:

- Variable changes
- Function calls
- Return values
- Loop iterations
- Recursion stack
- Console output
